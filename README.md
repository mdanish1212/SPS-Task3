# CardioPredict Dashboard — Bootstrap + jQuery

Responsive front-end dashboard recreated from the supplied design.

## Technologies
- Bootstrap 5.3.3 — installed locally with npm (no CDN)
- jQuery 3.7.1 — installed locally with npm (no CDN)
- Custom CSS — only for CardioPredict theme, charts and visual details

## Install
1. Open this folder in VS Code.
2. Open Terminal.
3. Run:

```bash
npm install
```

This creates `node_modules` and installs Bootstrap + jQuery locally.

## Run
Use VS Code Live Server and open `index.html`. The HTML loads Bootstrap and jQuery from `node_modules`, so there are no CDN dependencies.

## Responsive
The dashboard is optimized for desktop/web, tablets and Android-sized screens. The dashboard grids collapse automatically, large tables scroll horizontally, and unnecessary sidebar artwork/spacing is hidden on small screens.

## Sections
Dashboard, Predict Disease, Patient Records, Analytics, Reports and Settings.

## Important
The risk calculation is only an illustrative front-end demonstration. It is not a clinically validated diagnostic model and should not be used for medical decisions.
